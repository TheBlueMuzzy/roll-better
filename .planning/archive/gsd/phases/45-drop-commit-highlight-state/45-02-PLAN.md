**Create `src/components/CommittedDie.tsx`:**

A simple visual-only die (no Rapier physics body). Pattern after the existing die mesh in PhysicsDie or UnlockableDie but stripped to just the visual:

- Props: `value: number, color: string, position: [number, number, number]`
- Render a die mesh at the given world position
- Use `getFaceUpRotation(value)` for correct face orientation
- Use the same die geometry/material as other dice (import from shared die assets — check how PhysicsDie or Die.tsx does it)
- **Highlighted appearance:** Use a slightly emissive version of the player color. Options (choose simplest):
  - Add `emissive={color} emissiveIntensity={0.3}` to the meshPhysicalMaterial
  - OR: Use a subtle pulse on emissiveIntensity in useFrame (0.2 to 0.4, slow sine wave)
  - OR: Add a wireframe outline mesh (like the existing OUTLINE ring on UnlockableDie but as a full wireframe)
- Keep it simple — the key is that committed dice look visually distinct from pool dice. A gentle emissive glow is sufficient.
- Die sits at Y = DIE_SIZE / 2 (table level)

**In Scene.tsx:**

- Subscribe to `committedUnlocks` from the store
- During unlock phase, render CommittedDie for each entry:
```tsx
{committedUnlocks.map((cu, i) => (
  <CommittedDie
    key={`committed-${cu.slotIndex}`}
    value={cu.value}
    color={player.color}
    position={cu.position}
  />
))}
```
- Only render when phase === 'unlocking' (they disappear when mitosis starts in Phase 46)
